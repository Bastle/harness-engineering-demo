## 开工前 Checklist

- [ ] 读完了 feature_list.json，确认这个任务可以开始
- [ ] 确认依赖任务已经完成（`state` 为 `passing`）
- [ ] 读了相关的现有代码，理解影响范围
- [ ] 向用户确认了你要做什么
- [ ] 准备好了验证命令
- [ ] **列出了计划修改的文件清单**（来自任务的 `files` 字段）
- [ ] **列出了不会修改的文件清单**（明确边界）

## 工作中 Checklist

- [ ] 一次只做这一件事
- [ ] 每完成一个小步骤就验证一次
- [ ] 遇到问题立即报告
- [ ] 保持代码风格一致
- [ ] **只修改了计划内的文件**（对照 `files` 字段）
- [ ] **没有"顺手"改其他代码**
- [ ] **没有升级依赖版本**
- [ ] **没有改配置文件**（除非任务要求）

## 完成后 Checklist

- [ ] 运行了 `make check`，全部通过
- [ ] 更新了 feature_list.json 的 `state` 为 `passing`
- [ ] 填写了 `evidence`（验证输出）
- [ ] 更新了 PROGRESS.md
- [ ] 写了清晰的 commit message
- [ ] 没有临时文件残留
- [ ] **运行 `git diff --name-only`，确认所有改动都在计划内**
- [ ] **单次提交改动不超过 300 行**
