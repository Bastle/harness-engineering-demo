# 项目状态汇总

## 概述

用命令取证后汇总项目状态。**不允许凭记忆回答**——feature_list.json 和
PROGRESS.md 的内容随时在变，只有刚跑过的命令和刚读的文件才算数。

## 何时使用

用户问"现在什么进度""做到哪了""还剩什么""总结一下项目情况"这类问题时。

## 操作步骤

1. 运行 `make status`，拿到功能项状态统计。
2. 读 `feature_list.json`，提取每个功能项的 id / behavior / state。
3. 读 `PROGRESS.md` 的「已完成」「进行中」「下一步」三节。
4. 按下面的输出格式汇报。

## 输出格式约定

功能项用三列表格：

| ID | 行为 | 状态 |
|----|------|------|
| F01 | …… | not_started |

表格之后给出：
- **进行中**：WIP 项（若有），一句话说明卡在哪
- **建议下一步**：从 PROGRESS.md「下一步」取第一条，不要自创任务

## 常见错误

- 凭记忆回答状态，没跑 `make status`、没读文件——**必须取证**
- 把 `not_started` 说成"快完成了"，把计划说成事实
- 自创"下一步"，而不是引用 PROGRESS.md 的「下一步」
